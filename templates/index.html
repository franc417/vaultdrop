// how it works

01
AES-256-GCM encryption
File is encrypted with a PBKDF2-derived key (260k iterations) before touching disk. Server never sees plaintext.
02
Burn-after-read
Ciphertext is permanently deleted from the server the moment the download limit is reached. No recovery possible.
03
Fragment key (no-log)
Auto-generated keys live in the URL fragment (#key). Fragments are never sent to the server — not in logs, not in analytics.
